About Color Picker Pro

Color Picker Pro is a sleek, offline-first Chrome extension designed for developers and designers. It allows you to pick colors from any website, convert between HEX, RGB, and HSL formats, and manage custom palettes.

How it Works

Once installed, click the extension icon or use a keyboard shortcut to open the picker. You can extract colors from web pages using the built-in EyeDropper tool, pin a floating color widget to your screen, and easily organize your favorite colors into palettes. The extension works entirely on your device with no data collection.

Keyboard Shortcuts

  • Ctrl + Shift + P — Open Color Picker
  • Ctrl + Shift + K — Copy last picked color
  • Ctrl + Shift + E — Activate EyeDropper

Note: macOS users should use the Cmd key instead of Ctrl.
